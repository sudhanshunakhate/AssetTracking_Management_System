1. End-to-end stock flow

Masters feed catalog → inbound creates stock → issue / transfer / return / gatepass move custody. Requisition does not post stock until Issue.

flowchart LR
  ORG[Org / Store] --> OST[Opening Stock]
  ORG --> GRN[GRN]
  ITEM[Item Master] --> OST
  ITEM --> GRN
  ITEM --> SR[Requisition]
  VND[Vendor] --> GRN
  EMP[Employee] --> SR
  EMP --> ISS[Store Issue]
  OST --> STK[Stock / BLS]
  GRN --> STK
  SR --> ISS
  STK --> ISS
  STK --> TRF[Transfer]
  STK --> GP[Gatepass]
  ISS --> RTN[Return]
  RTN --> STK

flowchart LR
