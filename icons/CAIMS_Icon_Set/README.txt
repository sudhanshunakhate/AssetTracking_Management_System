CAIMS Standardized Icon Set
============================
32 icons used across the sidebar navigation and dashboard of the CAIMS UI.

Formats included:
- /svg               Vector icons (infinitely scalable, crisp at any size). Use these for the web app.
- /png               512x512px, white background — ready for docs, slides, print.
- /png-transparent   512x512px, transparent background — for overlaying on any color/UI.

Style spec (for consistency if you add more icons later):
- Grid: 20 x 20 viewBox
- Stroke: 1.7px, round caps and joins, no fill (outline style)
- Color: currentColor in the app (inherits active/hover state); #1e293b (slate) in these exported files
